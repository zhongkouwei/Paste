# Paste 7.0.2 对齐与发行验收

更新时间：2026-10-21，Asia/Shanghai。状态：进行中。原始目标不缩减为“一个类似 Paste 的页面”：分析本地安装的 Paste，独立重建其功能与页面，完成像素级比对，并达到可对外提供的标准。

## 证据与边界

- 参考程序：`/Applications/Paste.app`，Info.plist 中 CFBundleShortVersionString 为 7.0.2。
- 本轮通过原生 UI 检查主浮层、搜索、筛选、卡片右键、Pinboard 创建/重命名/删除、预览入口、通用/隐私/快捷键/智能设置。
- 观察到 Pinboard 创建立即生成“未命名”，在导航中内联编辑；Escape 结束编辑后空 Pinboard 仍存在。检查产生的空 Pinboard 已删除，确认列表恢复为原来的两个标签。
- 参考截图可能包含用户剪贴板内容，因此不提交到仓库，也不把这些内容用作 fixture。测试和截图只使用合成样本。
- 未提取 Paste 的程序代码、品牌资源或数据库；未绕过订阅或系统安全拦截。参考应用的订阅、iCloud 和 MCP 不等于本项目可直接调用的服务。

## 发布门槛

1. 功能矩阵中的缺口全部完成或由用户明确确认范围变更；不得自行把缺失能力从目标删除。
2. 形成带合成相同样本的参考/实现截图集，覆盖主浮层、搜索、类型、Pinboard、预览、设置、空/错误/权限状态。建立并执行像素差阈值，几何测试不替代视觉差分。
3. 真实跨应用、多屏、全屏、焦点恢复、系统重启和持续运行测试通过；不能用 TEST_MODE 的 IPC 测试推断原生粘贴已全面通过。
4. 数据迁移、原图、保留策略、恢复、容量/性能与隐私验证通过；未加密或未删除的副本要明确记录，不声称安全擦除。
5. Developer ID 签名、公证、staple、Gatekeeper、真实安装、升级回滚与目标架构全部通过。当前缺少有效 Developer ID 是此项的外部依赖，不阻止继续功能开发。
